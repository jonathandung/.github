# Please remove this file from your derived repo

This repository stores the governance, conduct code, contributing, and AI use documents I link to, copy from and implicitly use in
[other projects of mine](https://jonathandung.github.io), as per
[the GitHub docs](https://docs.github.com/en/communities/setting-up-your-project-for-healthy-contributions/creating-a-default-community-health-file).

[I](https://github.com/jonathandung) made this a [public domain](https://creativecommons.org/publicdomain/zero/1.0/deed.en)
[template repository](https://docs.github.com/en/repositories/creating-and-managing-repositories/creating-a-template-repository) since I believe its
contents can apply to many organizations or users mainly working on simple, open-source initiative projects with minimal modifications. Feel free to
use it as such (create the repository named .github using this template and add commits on top) or copy select files into your own project directly,
but bear in mind to replace all instances of my email address ("jonathandung@yahoo.com") and username ("jonathandung") in the documents with yours.

Note that I intentionally omitted the security and support documents because they can vary a lot across projects, with portions such as installation
instructions and public security keys likely specific to each repository. The format is also up to personal preference.

If you found this helpful, credit me however you wish. Have a nice day.
